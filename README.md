# 宝哥提词器（微信小程序）

免费、不限台本条数、支持**角色多色高亮**与**零成本声控跟读**的提词工具。
v1.0 为纯提词方案（不做小程序内拍摄），面向口播与短剧创作者，免费换量、快速上线。

> 版本：v1.0 ｜ 形态：纯提词 + 声控跟读 + 角色高亮 ｜ 上次更新：2026-09-02

---

## 一、v1.0 功能清单

| 功能 | 说明 |
|---|---|
| 我的台本 | 本地不限条数管理，支持新建 / 编辑 / 删除 / 续播进度 |
| 编辑与角色识别 | 自动识别 `【名】` / `（名）` / `名：` 三种角色格式，整行多色高亮；手动长按兜底标注 |
| 提词台 | rAF 插值平滑滚动、横竖屏、屏幕常亮、虚拟裁剪、后台暂停保护、开场倒计时、补光灯 |
| 声控跟读 | 本地分析录音音量判断是否在说话，有声即滚、静音 800ms 即停；音频不上传、零成本、零延迟 |
| 显示设置 | 字号 / 语速 / 行距 / 字距 / 配色（黑底高对比 + 白底深色版）/ 参考线开关 |
| 手动控制 | 拖动定位、暂停、快进快退、从头开始 |
| 角色配色 | 8 色按出场频次分配，白底模式自动切换深色版，支持自定义覆盖色 |

**已确认不做（v1.0）**：小程序内 `camera` 录制 —— 用户已确认暂不需要，建议 v1.1 评估。

## 二、本地运行

1. 用**微信开发者工具**（Stable 版）打开本目录 `baoge-teleprompter/`（选「导入项目」→ 目录指向此处）。
2. 把 `project.config.json` 里的 `"appid": "touristappid"` 换成你自己的小程序 AppID。
   - ⚠️ 声控跟读用到录音接口，**游客模式（touristappid）下录音不可用**，必须用真实 AppID 才能测声控。
3. 编译预览即可。

> 数据默认存本地（`wx.setStorageSync`），无需后端、无需云开发即可跑通 v1.0 全部功能。

## 三、送审前置清单（上线前必做）

| 项 | 做什么 | 在哪做 |
|---|---|---|
| AppID | 替换为真实 AppID，且主体类型建议用**企业**（涉及用户内容存储） | 微信公众平台 →  development 设置 |
| 隐私保护指引 | 必须配置《隐私保护指引》，并在指引中声明「麦克风（录音）」用途 | 微信公众平台 → 设置 → 服务内容 / 隐私 |
| 隐私弹窗 | 代码已内置 `wx.requirePrivacyAuthorize` 授权闸门，用户首次用声控会弹窗同意 | 已处理（engine/vad.js） |
| 应用图标 | 上传 144×144 / 1024×1024 PNG 图标 | 微信公众平台 → 基本设置（图标不在代码仓库） |
| 名称 | 「宝哥提词器」**已核实未被占用**，可直接用 | 微信公众平台 → 设置 → 基本设置 → 名称 |
| 类目 | 建议选「工具 > 实用工具」或「生活服务」 | 微信公众平台 → 服务类目 |
| 简介 | 突出「不限台本数 / 角色高亮 / 声控跟读」差异化 | 送审信息 |

> 注意：录音接口若未在隐私指引声明，审核会直接驳回，且真机运行 `authorize(scope.record)` 会被系统拦截。

## 四、技术架构（一句话）

原生小程序 + 纯本地引擎（不引组件库、不建后端）：
- `engine/parser.js` 预计算行数组（不靠 CSS 换行，才能定位「读到第几行」）
- `engine/role.js` 角色识别 + 8 色配色（黑底/白底双色板）
- `engine/scroll.js` transform + rAF 插值滚动
- `engine/vad.js` 本地 PCM 能量 VAD 声控跟读 + 隐私授权闸门
- `engine/prefs.js` / `engine/store.js` 偏好与台本本地 CRUD
- `pages/` 四个页面：我的台本 / 编辑 / 提词台 / 设置
