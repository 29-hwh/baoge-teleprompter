二、怎么守住的「悟空不动」

约束是「规则修改只改智能多模态，悟空专属拆分规则不要变动」。五处改动里，四处天然落在悟空不经过的路径上；只有一处是共用的，必须专门隔离。

修复改动位置悟空是否经过隔离手段
P1sliceByBoundaries否（悟空只处理表格，原文 raw.split('\n')）天然隔离
P2splitTableLegacy是加参数隔离：仅多模态传 {contentPick:true}，悟空调用点加了「勿改」护栏注释
P3findHeadingBoundaries否天然隔离
P4splitDialogueCell否（悟空不走此函数）天然隔离
P5isPlaceholderLine否（悟空不过滤，原样保留）天然隔离
共用函数的隔离写法 
// 多模态（splitTableScript 内）—— 启用内容评分
segments.push(splitTableLegacy(tbl, ep, headings && headings[i], { contentPick: true }))

// 悟空（splitTableScriptWukong 内）—— 保持原几何推断
// ⚠️ 悟空规则锁定：这里**不要传 { contentPick: true }**。

三、每条修复的具体效果

P1 · 前言不再消失

根因sliceByBoundaries 从 idxs[0] 起切，第一个标题之前的内容从未进入任何输出块。
影响入口preview.js 的「智能拆分（纯文字档）」按钮 —— 真实用户流程。
修复前01 短剧丢「剧名：《掌心暗渡》」；04 话剧丢整张「出场人物：…」表
修复后三段前言全部保留；01 切 4 篇、04 切 5 篇、09 切 3 篇

P2 · 整篇丢失 → 恢复（红线级）

根因legacy 只有一条几何判据「≥4 列取末列」，默认台词总在最右。但拍摄脚本表最常见的排布是「镜号/画面/台词/备注」，末列是空的备注列 → 整篇 0 行、不报错。
新判据逐列打分：「角色名：台词」前缀权重最高(3)；通过 cellLooksLikeDialogue 计 1；整列大量为空乘 0.3 惩罚。全部 0 分时返回 -1，退回原规则——宁可不改也不错改。
修复前T5b 多模态 0 行（整篇丢失）
修复后T5b 多模态 4 行，取到的是台词列而非备注列

P3 · 两条路径口径统一（含一次口径变更）

根因智能拆分用 EP_HEAD_RE（集/期/话/卷/部），按标题拆用 HEAD_LINE_RE（含幕/场），同一份稿给出不同答案。
修法两级回退：一级命中集/期/话/卷/部就只用它；二级（幕/场/回/章）仅在全稿没有任何一级边界时才启用。
为什么不是一律认幕混合稿「第1集 → 第二幕 → 第2集」里，第二幕是第 1 集内部的结构标记，切开就破坏了按集推进。这一点被回归 case 12 明确锁着，必须保住。
修复后纯幕稿件：智能拆分 5 篇 = 按标题拆 5 篇 ｜ 混合稿：仍按集拆 2 集（老行为不变）
⚠️ 口径变更需要知道的一件事

这一条改的是产品行为而非纯 bug 修复：纯话剧（全篇无「第N集」）现在会按幕拆成多篇，过去是整篇 1 集。

因此更新了 docx_split_real.test.js 里 4 条记录旧口径的断言（「幕≠集，不应按第一幕/第二幕拆分」等），并在用例内写明了作废原因与日期。这是在 PASS/FAIL 上如实标注的口径迁移，不是掩掉失败。该套件现已 27/27 通过，且新增了一条「幕内容不串篇」的零遗漏断言。

P4 · 直角引号台词能归属角色了

现象台词不丢字，但角色归属 0/6 —— 不高亮、躲过按角色筛选。
修法normalizeCornerQuote：把「母亲｢回来啦。｣」规范化成「母亲：回来啦。」。只认两个安全位置：① 段首 ② 紧跟句末标点或另一个闭合引号之后（「沈亦｢别——｣母亲｢吃完再走。｣」）。行中间的「他跟我说｢好的｣」是引用，绝不当说话人。
修复前母亲｢回来啦，先洗手。｣
修复后母亲：回来啦，先洗手。　（角色覆盖 0/6 → 5/5）
悟空侧仍保留原文 母亲｢回来啦，先洗手。｣，未被规范化 ✅

P5 · 占位形态补全

新增认无・（无）・(无)・无台词・（无对白）・- —・/・N/A
三条防线① 严格整行匹配，带说明的「（无台词，手机屏照亮她的脸）」不认 ② 长度 ≤ 6 字，「无力站起来还得帮他搬完」不认 ③ 空行仍不算占位行
修复后T7 多模态滤掉孤立的「无」（4 行 → 3 行）；悟空侧仍保留「无」（规则锁定）✅

五、遗留与提醒

1. T5b 在悟空侧仍输出 0 行（有意保留）

P2 的根因同时存在于悟空的 legacy 兜底路径。按「悟空规则不变」的指令，悟空侧未启用内容评分。若将来要放开，只要在 splitTableScriptWukong 那一行补上 {contentPick:true} 即可，其余代码无需改动。

2. 91-100 的人工样张里没有占位行

用最新的真实稿件 建华&小凤的生活91-100.docx 与 …91-100台词.docx 对账时发现：人工整理的样张没有保留「（无台词）」这类占位行，而悟空规则是「忠实保留」。这不影响本轮修复，但意味着「悟空规则」与「人工习惯」在这一点上存在出入——要不要让悟空也去掉占位行，建议下次单独定。
